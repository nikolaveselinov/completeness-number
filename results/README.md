# Computed data

- [`census/`](census) contains the canonical 1,352-row table and family
  summaries.
- [`detailed/`](detailed) contains expanded per-level data for 1,266
  characteristics.
- [`q2_degree8_compact/`](q2_degree8_compact) contains the compact binary
  degree-eight tables.
- [`q2_degree9_e_only/`](q2_degree9_e_only) contains the binary degree-nine
  summary.

See [`../docs/data.md`](../docs/data.md) for column definitions and the
relationship among these sources.
