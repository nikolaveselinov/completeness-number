# Expanded level data

These tables contain the fully expanded results for 1,266 characteristics:

- `characteristics.csv` gives the exact completeness number and computation
  totals for each characteristic;
- `degree_data.csv` aggregates complete and incomplete prime levels by level
  degree; and
- `incomplete_levels.csv` lists every incomplete level and its zero Brandt
  entries.

The remaining 86 characteristics in the canonical census are represented by
the compact binary degree-eight and degree-nine tables in the neighboring
directories. See [`../../docs/data.md`](../../docs/data.md) for the complete
data map.
